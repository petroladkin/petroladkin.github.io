About

Product Engineer. I take products from idea - or from stuck - to production. Robotics, backend, mobile; now with AI agents.

I'm a software engineer in Chernivtsi, Ukraine. I wrote my first program in 1995 and have been paid to write software since 2006. The stack has changed every few years; the job has not: I take a product at whatever stage it is in and get it to production.

The stages I've picked products up at:

  • Stalled, as a junior: rewrote SecurePhone for Windows Mobile in C++ alone and shipped it.
  • An idea: KeyReel - proof of concept, MVP, a product on five platforms, a US patent I co-invented.
  • A domain I had never seen: learned ROS and had a robot MVP driving on the map in about two months.
  • An empty repo: a ROS 2 adapter for the company's robots, taken to release 1.0 in ten months.
  • An existing app: the fleet operator UI, rewritten in React in 4 calendar days with a team of AI agents.

How I work now. I own intent, specs, acceptance and release, and direct AI agents to build and review what is needed, so rework and heavy code review stop being the cost of a change. I built a multi-model code-review command for it - six specialist agents plus an arbiter - now used in four repos.

What I'm building. My own open-source tools, made the same way. The first is hookwitness: a self-hosted webhook catcher with verdicts - signature and JSON Schema checks, fault scenarios, live UI, reports, REST API and MCP. Try it. More in Portfolio.

The range. Robotics (ROS 2), backend (Go, .NET), mobile. Also embedded (STM32), iOS and macOS, security and VoIP, code generation, leading small teams, co-founding a startup. Further back: Windows Mobile, Unity and AR. Some of it lasts: the PhoneCrypt iOS core I wrote was still in use around 2024.

Co-inventor of US patent 10,764,056 "Short-distance network electronic authentication" (2020). The full story: Experience.
