hookwitness

Self-hosted webhook catcher with verdicts: signature and JSON Schema checks, fault scenarios, live UI, reports, REST API and MCP.

Go | Docker | REST API | MCP

Self-hosted: container image or one binary

Github

Catch webhooks, get a verdict, attach the evidence.

Status: 0.1, the first release (v0.1.0, October 2026). Apache License 2.0.

  • A verdict for every request. Signatures (GitHub, Stripe, Standard Webhooks, any HMAC), bearer tokens, Basic credentials and JSON Schema, each pass or fail with the reason.
  • Faults on purpose. Fail every Nth delivery or the first N, answer late, hang, reset the connection, and watch the sender's retries.
  • Evidence for the ticket. A Markdown, HTML or PDF report of what arrived and what was answered.
  • REST API and MCP server. Everything the UI does, plus long-poll waits and an expect assertion for agents.

Try it:

docker run -d --name hookwitness -p 127.0.0.1:8080:8080 -v hookwitness:/data \
  ghcr.io/petroladkin/hookwitness:0.1

Then open http://127.0.0.1:8080/admin/ and create an endpoint. Quick start, documentation and the comparison with other tools are in the repository.
